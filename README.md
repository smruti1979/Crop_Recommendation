# Intelligent Crop Selection Advisor that leverages machine learning to optimize crop selection
Overview
The Intelligent Crop Selection Advisor is a web-based application designed to assist farmers, agricultural students, and enthusiasts in selecting the most suitable crops to cultivate based on specific environmental parameters. By analyzing factors such as soil type(Nitrogen,Phosphorus,Potassium, pH), climate conditions(Temperature, Humidity, Rainfall), the system provides tailored recommendations that aim to optimize crop yield, ensure sustainability, and enhance agricultural productivity.

Key Features
User-Friendly Interface: An intuitive and easy-to-navigate interface that enables users to input their data effortlessly.
Real-time Recommendations: A robust Machine learnign algorithm (RandomForestClassifier) that analyzes user input in real-time to generate crop suggestions.
Interactive Visualization: Engaging visual displays of recommended crops.

Technology Stack
Frontend: HTML, CSS.
Backend: Python (Flask ) for server-side operations.
Machine Learning: Scikit-learn for implementing prediction algorithms that enhance recommendation accuracy.

Installation
To set up the Intelligent Crop Selection Advisor on your local machine, follow these steps:

Clone the repository:
git clone https://github.com/smruti1979/Crop_Recommendation.git

Navigate to the project directory:
cd Crop_Recommendation
Open the project in VS Code and run app.py

Visit http://127.0.0.1:5000 (or the port specified) in your web browser to use the application.

Usage
Enter the required parameters such as soil type(Nitrogen,Phosphorus,Potassium, pH), climate conditions(Temperature, Humidity, Rainfall) in the input fields.
Click the “Recommend Crop” button to receive suitable crop based on your inputs.
